# ADR-0010: 工作区统一授权与发布边界

有效工作区成员可以访问该工作区的所有项目，不设逐项目成员名单。所有者与编辑者都可创作和预览；只有所有者可以发布、删除项目或更改公开状态。未发布预览仅对成员开放，已发布应用的访问仍无需平台登录。工作区所有者通过绑定邮箱、单次使用、七天有效的邀请添加成员，未接受的邀请可撤销；工作区始终至少保留一位所有者。

这一边界取代 ADR-0005 中所有构建产物凭不可猜测链接即可访问的规则。工作区统一授权减少首版权限组合；限制未发布预览避免链接泄露暴露工作内容，同时保留发布应用的公开传播能力。代价是原先依赖未发布 `/app/<id>/` 链接的访问方式需要调整。

首版不提供项目跨工作区搬迁。项目始终归创建时选定的工作区，成员退出或账户停用不改变项目归属。

团队工作区的唯一所有者不能直接退出，须先指定另一位所有者；否则只能继续留任或删除工作区。仅所有者可删除团队工作区，删除前明确警告；删除后项目和已发布应用立即不可访问。个人工作区不参与所有者转交。

团队工作区所有者可以将编辑者升为所有者、将其他所有者降为编辑者或移除成员；不得降级或移除最后一位所有者。成员资格或角色变化应立即影响后续访问与操作。

取消公开后，原应用链接及其模拟支付入口立即停止匿名访问；发布历史仅工作区成员可见，再次发布可沿用原链接。竞赛中未胜出的版本始终只允许工作区成员回看，即使正式应用已发布也不公开。

所有者发出邀请时可指定所有者或编辑者角色，默认编辑者；接受邀请后按发出时确定的角色加入工作区。
