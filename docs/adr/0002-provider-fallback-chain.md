# Provider 三级兜底链

生成引擎为可插拔的 Provider 接口，运行时按 DeepSeek（主）→ 本地 gemma（备）→ TemplateProvider（模板兜底）的顺序容错：主 Provider 失败或文件校验不通过时逐级降级，模板引擎保证任何环境下都必有产物可预览。

本地 gemma（192.168.1.101:8090，llama.cpp 服务）在平台部署于家庭 k8s 时可达，但它是约 31 token/s 的推理模型且输出含 `reasoning_content`，因此只作备选；其可用性在启动时探测，不在线则自动从回退链与竞赛参赛者中摘除。模板兜底与"智能体驱动生成"的叙事并不矛盾——它是可靠性边界，在任何演示环境下兜底可用性。
_Avoid_: 为了叙事纯粹性而放弃兜底（评审现场网络故障时无产物可展示）。
